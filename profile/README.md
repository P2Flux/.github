## P2Flux

Programmable, non-custodial payment infrastructure for internet businesses.

Payments move buyer wallet → recipient wallet, with the fee split out in the same transaction. No
custody, no balances, no accounts.

| | |
|---|---|
| [docs](https://github.com/P2Flux/docs) | integration guide and result codes |
| [contracts](https://github.com/P2Flux/contracts) | Solidity, ABIs, EIP-712 definitions |
| [sdk-js](https://github.com/P2Flux/sdk-js) | JavaScript/TypeScript client |
| [sdk-php](https://github.com/P2Flux/sdk-php) | PHP client |

Live on Base Mainnet (chain 8453) with USDC; a full test environment runs on Base Sepolia. Docs: https://p2flux.com/docs/
